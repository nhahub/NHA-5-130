🔬 Key Architectural Breakthroughs

  • Shared Encoder Representation: Twin ResNet/U-Net encoder paths guarantee temporal invariance across seasonal illumination changes.
  • Differential Fusion Layer: Combines absolute difference |A - B| with concatenated representations [A, B] to highlight building boundary alterations.
  • Severe Class Imbalance Mitigation: Changes represent under 5% of pixels. Weighted BCE with pos_weight=10.0 paired with Soft Dice prevents trivial all-zero background convergence.
  • Morphological Post-Processing Pipeline: Opening with 3×3 kernel eliminates satellite sensor noise; closing fills internal building courtyard voids.
