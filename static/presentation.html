Executive Summary

The Challenge of Automated Remote Sensing Change Detection

🚨 The Urban Monitoring Crisis

  • Severe Inspection Latency: Manual visual photointerpretation takes weeks or months across expanding metropolitan zones.
  • Severe Illumination & Seasonal Noise: Sun angles, soil moisture, and seasonal foliage changes create 80%+ false alarms with traditional differencing algorithms.
  • Critical Class Imbalance: Actual building structural alterations represent less than 5% of total pixels; standard deep networks predict all zeros.

💡 Our SOTA Solution

  • Weight-Shared Siamese Twin Encoders: Ensure temporal feature symmetry across multi-year bi-temporal aerial pairs.
  • Dual Differential Fusion (|A - B| + [A, B]): Explicitly models boundary alterations while preserving spatial context.
  • Weighted BCE (w=10) + Soft Dice Objective: Forces gradient propagation onto building edges despite severe class imbalance.
  • Sub-Second GPU Inference (<800ms): Interactive web studio with swipe curtain comparison and geospatial footprint stats.

Deep Learning Architecture

Siamese U-Net with Diff-Cat Fusion Mechanism

Core Innovation: Twin encoders extract deep hierarchical feature maps from Time 1 (A) and Time 2 (B) with shared weights. At the bottleneck, the Diff-Cat Fusion Block computes both the element-wise absolute difference |F_A - F_B| and concatenated features [F_A, F_B], guiding the U-Net decoder with skip connections to accurately localize change boundaries.

Mathematical Formulation

Loss Function Formulation: Solving Severe Class Imbalance

1. Pos-Weighted Cross-Entropy (w = 10.0)

Penalizes false negatives 10× more aggressively than false alarms:

L_wBCE = - [ 10.0 · y · log(p) + (1 - y) · log(1 - p) ]

Forces the gradient to actively update on rare building pixels instead of converging to an all-zero background.

2. Soft Dice Loss (Boundary Invariance)

Directly optimizes the spatial overlap ratio (IoU):

L_Dice = 1 - [ 2·∑(p·y) + ε ] / [ ∑(p) + ∑(y) + ε ]

Combined Hybrid Objective: L_total = L_wBCE + L_Dice balances boundary crispness and pixel-level certainty.
